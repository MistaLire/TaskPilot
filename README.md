TaskPilot

TaskPilot — Telegram-бот для управления личными задачами. Проект создан на Python с использованием SQLite для хранения данных.
Возможности

    Создание и просмотр задач.

    Удаление задач.

    Отметка выполнения.

    Установка сроков выполнения.

    Напоминания о задачах.

    Приоритеты задач.

    Категории задач.

    Хранение данных в SQLite.

    Удобный список задач в одном сообщении Telegram.

Технологии

    Python

    python-telegram-bot

    SQLite

    python-dotenv

Установка и запуск
1. Клонирование проекта

git clone https://github.com/ТВОЙ-ЛОГИН/TaskPilot.git
cd TaskPilot

Вместо ТВОЙ-ЛОГИН укажи свой логин GitHub.
2. Создание виртуального окружения

py -m venv .venv

3. Установка зависимостей

Windows:

.\.venv\Scripts\python.exe -m pip install -r requirements.txt

4. Настройка токена

Создай файл .env в корневой папке проекта и добавь в него:

BOT_TOKEN=твой_токен_от_BotFather

Не публикуй файл .env и никому не передавай токен бота.
5. Запуск

.\.venv\Scripts\python.exe bot.py

TaskPilot — учебный проект для изучения Python, Telegram Bot API, работы с SQLite и организации кода небольшого приложения.
